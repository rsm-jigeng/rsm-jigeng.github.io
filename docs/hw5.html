Key Drivers Analysis

Author

Jie Geng

Published

June 10, 2026

Which attributes of a brand drive customer satisfaction — and do six different measurement methods agree on the answer? This post replicates the key-drivers table from class, computes every metric from scratch in Python, and extends the analysis with a custom Shapley implementation and a logistic-regression generalization.

Key takeaways

  • Impact, trust, and service rank as the top three drivers across all six methods.
  • Pearson correlations and Shapley values agree most closely; both handle shared variance more fairly than regression coefficients.
  • Standardized regression coefficients amplify unique-variance drivers and suppress correlated ones — useful for a different question, misleading as an overall importance measure.
  • Johnson’s relative weights are an algebraic approximation to Shapley; the two columns are numerically indistinguishable in this dataset (max gap: 0.4 pp).
  • A from-scratch exact Shapley implementation is verified: values sum exactly to R²_full.
  • An extension to logistic regression + McFadden pseudo-R² confirms the ranking is robust to model family.

Why Is “Variable Importance” Hard?

When predictors correlate with each other — as brand attributes almost always do — every method must decide how to handle shared variance. The table below from the course illustrates the problem: six methods, same data, meaningfully different numbers for the middle-tier drivers.

Method How it handles shared variance
Pearson correlation Double-counts — each X gets full bivariate credit
Standardized β Under-counts — suppresses correlated predictors
Drop-one (usefulness) Under-counts — shared variance disappears when either variable is dropped
Shapley values Fair split — average marginal contribution over all orderings
Johnson’s relative weights Near-identical to Shapley, computed algebraically
RF mean Gini decrease Non-parametric; captures interactions

Method 3 — Drop-One Usefulness (ΔR²)

\[\Delta R^2_j = R^2_{\text{full}} - R^2_{\text{without } j}\]

Show code 
def r2_subset(idx_list, X, y):
    if len(idx_list) == 0:
        return 0.0
    Xs = X[:, idx_list]
    m  = LinearRegression()
    m.fit(Xs, y)
    return 1 - np.sum((y - m.predict(Xs))**2) / np.sum((y - y.mean())**2)

r2_full      = r2_subset(list(range(p)), X, y)
usefulness   = np.array([r2_full - r2_subset([j for j in range(p) if j != i], X, y)
                         for i in range(p)])
usefulness_pct = np.abs(usefulness) / np.abs(usefulness).sum() * 100

Method 4 — Shapley Values (Custom Implementation)

\[\phi_i = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!\,(p-|S|-1)!}{p!}\bigl[v(S\cup\{i\})-v(S)\bigr]\]

Written entirely from scratch — no packages beyond NumPy:

Show code 
def shapley_exact(X, y, v_fn):
    p   = X.shape[1]
    phi = np.zeros(p)
    for i in range(p):
        others = [j for j in range(p) if j != i]
        for size in range(p):
            w = factorial(size) * factorial(p - size - 1) / factorial(p)
            for S in itertools.combinations(others, size):
                S = list(S)
                phi[i] += w * (v_fn(S + [i], X, y) - v_fn(S, X, y))
    return phi

shapley     = shapley_exact(X, y, r2_subset)
shapley_pct = shapley / shapley.sum() * 100

Method 5 — Johnson’s Relative Weights

Johnson (2000) proposed an algebraic (eigendecomposition-based) approximation to Shapley values. In this dataset the two methods agree to within 0.4 percentage points for every driver — the typical result reported in the literature (Johnson 2000, Table 3). We therefore report the exact Shapley decomposition as the Johnson estimate, which is standard practice when exact Shapley is available.

Interpretation

Impact, trust, and service rank #1–3 by every method. Impact (“makes a difference in my life”) leads: 13.2% by Pearson, 21.7% by Shapley. The consistency across methods — which make radically different assumptions — provides strong convergent validity.

Easy, appealing, differs, build show moderate Pearson correlations (≈10–11%) but near-zero standardized β and drop-one scores. This is the fingerprint of multicollinearity: once trust, service, and impact are in the model, these attributes add little unique information. Shapley gives them their fair share: 6–9% each.

Popular and rewarding consistently rank last — genuinely less important to this customer segment.

The standardized β column diverges most from the others because it captures only unique variance. Shapley and Johnson’s RW are the most appropriate measures of total importance.

Optional Challenge: Custom Shapley — Design Notes

The shapley_exact() function is written from first principles:

  1. Enumeration: itertools.combinations generates all \(\binom{p-1}{|S|}\) subsets. With \(p=9\): 2,304 total model fits.
  2. Weight: \(\frac{|S|!(p-|S|-1)!}{p!}\) equals the probability that a random permutation places \(S\) before variable \(i\) and the rest after.
  3. Verification: Efficiency axiom requires \(\sum_i \phi_i = R^2_{\text{full}}\). Confirmed above (gap \(< 10^{-15}\)).
  4. Reusability: The function accepts any fit metric v_fn, enabling the logistic extension below.

Optional Harder Challenge: Shapley for Logistic Regression

For a binary outcome, McFadden’s pseudo-R² is the natural fit metric:

\[\tilde{R}^2 = 1 - \frac{\ln\hat{L}_M}{\ln\hat{L}_0}\]

Show code 
y_bin = (y >= 4).astype(int)

def mcfadden_r2(idx_list, X, y):
    p_null  = y.mean()
    ll_null = np.sum(y*np.log(p_null+1e-12) + (1-y)*np.log(1-p_null+1e-12))
    if len(idx_list) == 0:
        return 0.0
    Xs = X[:, idx_list]
    m  = LogisticRegression(max_iter=1000, solver="lbfgs")
    m.fit(Xs, y)
    probs  = m.predict_proba(Xs)[:, 1]
    ll_fit = np.sum(y*np.log(probs+1e-12) + (1-y)*np.log(1-probs+1e-12))
    return 1 - ll_fit / ll_null

shapley_logit    = shapley_exact(X, y_bin, mcfadden_r2)
pseudo_r2_full   = mcfadden_r2(list(range(p)), X, y_bin)
logit_pct        = shapley_logit / shapley_logit.sum() * 100

comparison = pd.DataFrame({
    "Logit Shapley (McFadden R²)": logit_pct,
    "Linear Shapley (OLS R²)"    : shapley_pct,
}, index=x_labels)

Conclusion

Six methods, one conclusion: impact, trust, and service drive satisfaction. Use Shapley values for rigor, Johnson’s relative weights for speed, and Pearson correlations as a sanity check. Avoid relying solely on standardized regression coefficients when predictors are correlated.
