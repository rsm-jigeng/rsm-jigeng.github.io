Key Drivers Analysis

Author

Jie Geng

Published

June 7, 2026

Which attributes of a brand actually drive customer satisfaction — and how much do different measurement approaches agree? This post works through six methods of variable importance and compares what each reveals.

Key takeaways

  • Impact, trust, and service consistently rank as the top three drivers of satisfaction across all methods.
  • Pearson correlations and Shapley values tend to agree closely; standardized regression coefficients diverge more due to multicollinearity.
  • Johnson’s relative weights and exact Shapley decompositions both partition R² cleanly and are the most defensible all-around choices.
  • A custom Shapley implementation (from scratch) confirms the package results exactly.

Background: Why Multiple Methods?

Customer satisfaction surveys measure a single outcome — overall satisfaction — alongside a battery of attribute ratings. The natural question is: which attributes matter most? But “importance” is harder to pin down than it sounds. When predictors correlate with each other (as brand attributes often do), each method makes a different choice about how to handle that shared variance.

The six methods below each have a different answer to that question:

Method Core idea Handles collinearity?
Pearson correlation Bivariate association, ignores other predictors Partly (misses suppression)
Standardized β Marginal slope in a joint regression No — inflated/deflated by collinearity
Drop-one (usefulness) How much R² falls when one variable is removed Partially
Shapley values Fair allocation of R² across all variable orderings Yes — gold standard
Johnson’s relative weights SVD-based orthogonal approximation of Shapley Yes — fast approximation
Random forest Gini decrease Node impurity reduction averaged over trees Implicitly

The dataset contains 2,553 customer responses across 9 brand attribute drivers and one outcome (overall satisfaction, rated 1–5). All attribute variables are binary (0/1). The outcome variable satisfaction ranges from 1 to 5.

Method 1 — Pearson Correlation

The simplest approach: compute the bivariate correlation between each attribute and satisfaction. It ignores all other predictors, which means correlated attributes each receive “full credit” for shared variance.

Show code 
pearson_r = np.array([stats.pearsonr(df[c], y)[0] for c in x_cols])
pearson_p = np.array([stats.pearsonr(df[c], y)[1] for c in x_cols])

Method 2 — Standardized Regression Coefficients

Standardize all variables to mean 0, SD 1, then run OLS. The resulting coefficients (β) represent the change in satisfaction (in SD units) for a one-SD increase in each attribute, holding all others constant. Multicollinearity depresses the coefficients of correlated variables.

Show code 
scaler = StandardScaler()
X_std  = scaler.fit_transform(X)
y_std  = (y - y.mean()) / y.std()

lr_std = LinearRegression()
lr_std.fit(X_std, y_std)
std_betas = lr_std.coef_

Method 3 — Drop-One (Usefulness)

Fit the full model, then refit dropping each variable in turn. Usefulness = R²_full − R²_without_k. Variables that share little with others will show large drops when removed; redundant variables show near-zero drops.

Show code 
def r2_subset(idx_list, X, y):
    """Return R² of OLS using columns in idx_list. Returns 0 if empty."""
    if len(idx_list) == 0:
        return 0.0
    Xs = X[:, idx_list]
    m  = LinearRegression()
    m.fit(Xs, y)
    ss_res = np.sum((y - m.predict(Xs)) ** 2)
    ss_tot = np.sum((y - y.mean()) ** 2)
    return 1 - ss_res / ss_tot

all_idx = list(range(p))
r2_full = r2_subset(all_idx, X, y)

usefulness = np.array([
    r2_full - r2_subset([j for j in all_idx if j != i], X, y)
    for i in range(p)
])

Method 4 — Shapley Values (Custom Implementation)

Shapley values, borrowed from cooperative game theory, give each “player” (predictor) its average marginal contribution across all possible orderings (coalitions). For linear regression with R² as the fit metric, this is the gold-standard decomposition of explained variance.

The formula is:

\[\phi_i = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!\,(p - |S| - 1)!}{p!} \left[ v(S \cup \{i\}) - v(S) \right]\]

where \(v(S)\) is the R² of a model using only the variables in subset \(S\).

With \(p = 9\) predictors there are \(9! = 362{,}880\) orderings — feasible to compute exactly.

Show code 
def shapley_exact(X, y):
    """
    Exact Shapley value decomposition of R² for linear regression.
    Returns array of shape (p,) summing to R²_full.
    """
    p = X.shape[1]
    phi = np.zeros(p)
    all_idx = list(range(p))

    for i in range(p):
        others = [j for j in all_idx if j != i]
        for size in range(p):           # |S| = 0 … p-1
            weight = (factorial(size) * factorial(p - size - 1)) / factorial(p)
            for S in itertools.combinations(others, size):
                S = list(S)
                phi[i] += weight * (r2_subset(S + [i], X, y) - r2_subset(S, X, y))
    return phi

shapley = shapley_exact(X, y)

The Shapley values sum to 0.109, which equals R²_full = 0.109. ✓

Method 5 — Johnson’s Relative Weights

Johnson (2000) proposed an efficient approximation: orthogonalize the predictors via SVD, regress \(y\) on the orthogonal components \(Z\), then rotate the squared coefficients back to the original variable space. This partitions R² without the combinatorial cost of Shapley.

\[\text{RW}_k = \sum_{j=1}^{p} \hat{\lambda}_j^2 \cdot v_{jk}^2\]

where \(\hat{\lambda}_j\) are OLS coefficients on \(Z\) and \(v_{jk}\) are the right singular vectors from SVD of \(X\).

Show code 
Xc = X - X.mean(axis=0)
yc = y  - y.mean()

U, s, Vt = np.linalg.svd(Xc, full_matrices=False)
Z         = U * s                        # orthogonal components

lr_z = LinearRegression(fit_intercept=False)
lr_z.fit(Z, yc)
lam = lr_z.coef_                         # λ: coefficients on Z

# Rotate back: RW_k = Σ_j (λ_j · v_{jk})²
johnson_rw_raw = np.array([
    np.sum((lam * Vt[:, k]) ** 2) for k in range(p)
])

# Rescale so they sum to R²_full (minor numerical correction)
johnson_rw = johnson_rw_raw / johnson_rw_raw.sum() * r2_full

Johnson RW sum = 0.109 ≈ R²_full ✓

Method 6 — Random Forest Mean Decrease in Gini

A random forest trains hundreds of regression trees. At each node split, the reduction in node impurity (here: variance) is attributed to the splitting variable. Averaged over all trees and nodes, this gives a non-parametric importance measure that captures non-linearities and interactions.

Show code 
np.random.seed(42)
rf = RandomForestRegressor(n_estimators=500, max_features="sqrt", random_state=42)
rf.fit(X, y)
rf_importance = rf.feature_importances_

Interpretation

Impact, trust, and service are the top three drivers by every method. These three variables have the highest Pearson correlations (all ≥ 0.25), the largest Shapley R² contributions, and rank 1–3 on Johnson’s relative weights. This convergence across methods — which make very different assumptions about multicollinearity — gives strong confidence that these truly are the most important levers for satisfaction.

Build, differs, easy, and appealing form a middle tier. They have moderate Pearson correlations (≈ 0.18–0.21) but their standardized β coefficients are very small, and their drop-one usefulness scores approach zero. This pattern is a classic signature of multicollinearity: these attributes are intercorrelated with trust, service, and impact, so once those are in the model, the others add little unique variance.

Popular and rewarding consistently rank lowest. Their Pearson correlations are 0.17–0.19 — the weakest of the group — and their Shapley contributions are correspondingly small.

The standardized β column diverges most from the others. This is expected: in a regression with correlated predictors, coefficients reflect unique variance only, suppressing variables that share variance with others. The Shapley and Johnson’s RW methods are more appropriate when the goal is to understand total importance rather than a coefficient’s ceteris-paribus interpretation.

Optional Challenge: Custom Shapley — Code Walkthrough

The shapley_exact() function above is a from-scratch implementation. The key design choices are:

  1. Subset enumeration: itertools.combinations generates all size-\(|S|\) subsets of the other \(p-1\) variables. With \(p = 9\) this is \(\sum_{k=0}^{8} \binom{8}{k} = 256\) subsets per variable, × 9 variables = 2,304 model fits in total — manageable in seconds.

  2. Weight formula: The combinatorial weight \(\frac{|S|!\,(p-|S|-1)!}{p!}\) ensures that large and small coalitions both count, and that the contributions average fairly over all orderings.

  3. Verification: The sum of all Shapley values equals R²_full. The code confirms this: 0.10901 ≈ 0.10901. Any implementation error would break this identity.

Optional Hard Challenge: Shapley for Logistic Regression

For the harder challenge, I extend the Shapley decomposition to a logistic regression using McFadden’s pseudo-R² as the fit metric. This is appropriate when the outcome is binary; here I binarize satisfaction (≥ 4 = satisfied).

McFadden’s pseudo-R² is:

\[\tilde{R}^2 = 1 - \frac{\ell(\hat{\beta})}{\ell(0)}\]

where \(\ell(0)\) is the log-likelihood of the null model (intercept only) and \(\ell(\hat{\beta})\) is the fitted model log-likelihood.

Show code 
from sklearn.linear_model import LogisticRegression

# Binarize outcome: satisfied = 1 if satisfaction >= 4
y_bin = (y >= 4).astype(int)

def mcfadden_r2(idx_list, X, y):
    """McFadden pseudo-R² for logistic regression on columns in idx_list."""
    # null log-likelihood
    p_null = y.mean()
    ll_null = np.sum(y * np.log(p_null + 1e-12) + (1 - y) * np.log(1 - p_null + 1e-12))
    if len(idx_list) == 0:
        return 0.0
    Xs = X[:, idx_list]
    m  = LogisticRegression(max_iter=500, solver="lbfgs")
    m.fit(Xs, y)
    probs = m.predict_proba(Xs)[:, 1]
    ll_fit = np.sum(y * np.log(probs + 1e-12) + (1 - y) * np.log(1 - probs + 1e-12))
    return 1 - ll_fit / ll_null

def shapley_logit(X, y):
    """Shapley decomposition of McFadden pseudo-R² for logistic regression."""
    p = X.shape[1]
    phi = np.zeros(p)
    for i in range(p):
        others = [j for j in range(p) if j != i]
        for size in range(p):
            weight = (factorial(size) * factorial(p - size - 1)) / factorial(p)
            for S in itertools.combinations(others, size):
                S = list(S)
                phi[i] += weight * (
                    mcfadden_r2(S + [i], X, y) - mcfadden_r2(S, X, y)
                )
    return phi

shapley_logit_vals = shapley_logit(X, y_bin)
pseudo_r2_full = mcfadden_r2(list(range(p)), X, y_bin)

logit_df = pd.DataFrame({
    "Shapley (McFadden R²)": shapley_logit_vals
}, index=x_cols).sort_values("Shapley (McFadden R²)", ascending=False)

display(
    logit_df.style
    .format("{:.5f}")
    .background_gradient(cmap="Blues")
    .set_caption(
        f"Logit Shapley Values (McFadden pseudo-R² = {pseudo_r2_full:.4f})"
    )

The logistic Shapley ranking agrees closely with the linear results: impact, trust, and service remain the dominant drivers of the probability of being satisfied (≥ 4), confirming that the key-driver conclusions are robust to both the outcome specification and the model family.

Conclusion

Across all six methods, the message is consistent: impact, trust, and service are the primary levers for customer satisfaction. The middle-tier attributes (build, differs, easy, appealing) correlate with satisfaction in isolation but add little independent explanatory power — a typical result when brand attributes are positively correlated. The weakest drivers (popular, rewarding) are also those with the lowest bivariate correlations.

For practitioners, the recommendation is clear: if resources are limited, improving customer perceptions of impact (whether the brand makes a difference), trust, and service quality will yield the greatest returns in overall satisfaction.
